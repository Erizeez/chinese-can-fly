# 航空级传感器融合与惯性参考系统 (Avionics Sensor Fusion & IRS Engine)

---

## 一、 iPhone 传感器挖掘与硬件基准

iPhone 14 Pro 至 iPhone 18 Pro 配备了消费电子领域顶级的微机电传感器阵列：
1. **多频多星座 GNSS 接收机**：
   - 支持 GPS (L1 + L5 双频)、Galileo (E1 + E5a)、GLONASS、BDS (北斗三号 B1I + B1C + B2a) 以及 QZSS。
   - 双频 L5/E5a/B2a 具备更强的电离层穿透力与抗多径反射能力，高动态下几何高度精度可达 1~3 米。
2. **高动态 6 轴惯性测量单元 (IMU)**：
   - 3 轴高灵敏度陀螺仪（角速度范围通常达 $\pm 2000^\circ/\text{s}$）。
   - 3 轴高动态加速度计（支持高达 $\pm 16g$ 瞬时过载捕获，足以精确记录触地跳跃）。
   - 硬件采样率可通过 `CoreMotion` 设定最高至 100Hz。
3. **数字气压计 (Barometer / CMAltimeter)**：
   - 分辨率达 0.01 hPa（等效约 0.1 米海拔变化）。
   - 采样率 10Hz~50Hz，灵敏度极高，甚至能感知客舱空调鼓风微压差。
4. **3 轴磁力计**：
   - 提供地磁参考，结合 WMM (World Magnetic Model) 解算真北与磁北偏角。

## 二、 关键航空力学难题与数学突破

### 1. “客舱增压悖论”与双高解耦系统 (The Cabin Altitude Paradox)

#### 物理本质：
现代民航喷气客机巡航高度通常为 30,000 ~ 41,000 英尺（约 9,000 ~ 12,500 米）。在此高度外界气压仅 200~300 hPa，人几秒钟就会缺氧休克。因此飞机配备客舱增压系统（Environmental Control System, ECS），利用发动机引气或电动压缩机向密闭机舱加压。
- **巡航阶段**：无论飞机飞多高，客舱内压力始终被增压系统维持在相当于海平面至 6,000~8,000 英尺（约 1,800~2,400 米）的标准气压。
- **悖论后果**：如果飞行软件盲目使用 iPhone 气压计公式计算飞行高度，当飞机巡航在 36,000 英尺时，软件读数将永远卡在 7,500 英尺！

#### 解耦与融合方案：
“中国人能飞”首创**“双高度、双升降率、增压健康度”**三重并行体系：

```
                              传感器原始输入
                     +--------------+--------------+
                     |                             |
              [双频 GNSS 接收机]             [高灵敏度气压计]
                     |                             |
                     v                             v
           WGS84 椭球高 / 几何高            客舱环境气压 P (hPa)
                     |                             |
                     v                             v
         +-----------------------+     +-----------------------+
         | [1] 飞机真实飞行参数  |     | [2] 客舱增压监测系统  |
         | • 真实几何高度 (MSL)  |     | • 客舱等效高度 (Cabin)|
         | • 真实升降率 (VSI)    |     | • 客舱升降率 (CabinVSI|
         | • 地速与真实航迹角    |     | • 增压压差 ΔP (hPa)   |
         +-----------------------+     +-----------------------+
                     \                             /
                      \                           /
                       v                         v
               +-----------------------------------------+
               |  [3] 增压工况辨识与客舱舒适度评估引擎   |
               |  • 地面关舱门预增压检测                 |
               |  • 爬升/下降阶梯增压率 (Cabin FPM)      |
               |  • 泄压或突发失压告警监测               |
               +-----------------------------------------+
```

1. **客舱等效高度计算公式 (ISA 标淮反解)**：
   $$H_{\text{cabin}} = \frac{T_0}{L} \left[ 1 - \left( \frac{P}{P_0} \right)^{\frac{R \cdot L}{g_0}} \right]$$
   其中 $P_0 = 1013.25\text{ hPa}$，$T_0 = 288.15\text{ K}$，$L = 0.0065\text{ K/m}$，$g_0 = 9.80665\text{ m/s}^2$。
2. **通航无增压场景自动识别**：
   - 当检测到几何高度与气压高度的变化趋势高度重合且无压差平台期（如塞斯纳 172、滑翔机或无人机），算法自适应将气压计作为主高度微动参考，输出精密气压高度。

### 2. 机体坐标系自适应正交对准 (Aircraft Body Frame Alignment)

#### 物理本质：
手机的内置传感器坐标系（$S$ 轴：右 $X_s$、上 $Y_s$、屏幕外 $Z_s$）是随着手机随意摆放而变化的。而飞行员关心的是飞机机体坐标系（$B$ 轴：机头前向 $X_b$、机翼右向 $Y_b$、机腹垂直下向 $Z_b$）。

#### 对准算法推导：
1. **重力对齐阶段（垂直轴确定）**：
   当飞机在跑道静止或匀速滑行时，三轴加速度计的合矢量即为重力加速度矢量 $\vec{g}_s$。
   飞机垂直向下单位向量：
   $$\vec{z}_b^s = \frac{\vec{g}_s}{\|\vec{g}_s\|}$$
2. **滑跑加速阶段（机头航向轴确定）**：
   在起飞滑跑滑行起动（Takeoff Roll）阶段，飞机沿跑道方向产生显著的推力直线正加速度 $\vec{a}_{\text{thrust}}$（通常在 $0.2g \sim 0.4g$）。
   消除重力分量后，测量到的手机瞬时加速度为 $\vec{a}_{\text{user}}^s$。
   结合 GPS 航迹方向确定此时为直线滑跑，则机头前向单位向量 $\vec{x}_b^s$ 为：
   $$\vec{x}' = \vec{a}_{\text{user}}^s - (\vec{a}_{\text{user}}^s \cdot \vec{z}_b^s)\vec{z}_b^s, \quad \vec{x}_b^s = \frac{\vec{x}'}{\|\vec{x}'\|}$$
3. **右翼侧向轴确定**：
   $$\vec{y}_b^s = \vec{z}_b^s \times \vec{x}_b^s$$
4. **正交转换矩阵生成**：
   构建旋转矩阵 $R_s^b = [\vec{x}_b^s, \vec{y}_b^s, \vec{z}_b^s]^T$。从此，手机任意方向的采样值经 $R_s^b$ 转换后，直接映射为飞机的滚转（Roll）、俯仰（Pitch）和垂直过载（Nz）！

### 3. GNSS 辅助惯导扩展卡尔曼滤波 (GNSS-aided INS EKF)

#### 状态定义：
在当地东北天导航坐标系（NED）下，定义 16 维误差状态向量：
$$\delta x = [\delta p^n, \delta v^n, \phi, \delta b_a, \delta b_g]^T$$
- $\delta p^n \in \mathbb{R}^3$：位置误差
- $\delta v^n \in \mathbb{R}^3$：速度误差
- $\phi \in \mathbb{R}^3$：失准角（姿态四元数误差）
- $\delta b_a \in \mathbb{R}^3$：加速度计偏置误差
- $\delta b_g \in \mathbb{R}^3$：陀螺仪零偏漂移误差

#### 滤波流程：
- **机械编排（50Hz~100Hz 惯性积分）**：
  利用陀螺仪测得的机体角速度积分姿态四元数；将机体加速度转换至 NED 导航系并减去重力矢量后二次积分得到速度和位置。
- **GPS 观测更新（1Hz）**：
  当 GPS 产生新数据包时，构建观测残差：
  $$z_k = \begin{bmatrix} p_{\text{INS}}^n - p_{\text{GNSS}}^n \\ v_{\text{INS}}^n - v_{\text{GNSS}}^n \end{bmatrix} = H_k \delta x_k + v_k$$
  计算卡尔曼增益 $K_k$，更新状态后闭环校正 INS 姿态、位置与传感器零偏。
- **死推算（Dead Reckoning）**：
  客舱内走动或信号遮挡丢失 GPS 时，基于已在线标定的传感器零偏继续保持平滑航迹推算，绝不跳帧或界面卡死。

### 4. 关键飞行品质与力学指标解算

1. **垂直过载与触地 G 值冲击 (Touchdown G-Spike)**：
   - 采样率 50Hz 捕获着陆接地瞬间的瞬态垂向加速度峰值 $N_z$：
     - $N_z < 1.30g$：极度轻柔着陆（Butter Smooth Landing）
     - $1.30g \le N_z \le 1.60g$：标准适航范围着陆（Firm Landing）
     - $N_z > 1.80g$：重着陆（Hard Landing 警示）
2. **接地垂直沉降率 (Touchdown FPM)**：
   - 触地前 3 秒融合惯导与精密垂直速度，计算最后主轮接地时的垂直下沉速度（单位：英尺/分钟，fpm）。
3. **晴空湍流指数 (Turbulence EDR - Eddy Dissipation Rate)**：
   - 提取飞机巡航时垂直过载波动的高频残差，采用离散带通滤波与功率谱密度估计，解算国际民航组织 ICAO 标准湍流强度立方根 $\varepsilon^{1/3}$。
